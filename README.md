# 🚀 Amir AI Runner

**راه‌اندازی و مدیریت آسان مدل‌های آفلاین زبان بزرگ (LLM) روی سیستم شخصی شما**

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/Flask-2.0+-green.svg)](https://flask.palletsprojects.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)]()

Amir AI Runner یک ابزار قدرتمند و کاملاً رایگان است که به شما امکان می‌دهد مدل‌های زبانی بزرگ (مانند LLaMA، Gemma، Mistral و...) را به‌صورت کاملاً آفلاین روی کامپیوتر خود اجرا کنید. این برنامه با ارائه‌ی یک رابط کاربری وب زیبا و یک API سازگار با OpenAI، فرایند اجرای مدل‌های سنگین را به ساده‌ترین شکل ممکن تبدیل می‌کند.

- ✅ **پشتیبانی از فرمت‌های مختلف**: اجرای مدل‌های GGUF (فایل‌های `.gguf`) و Transformers (پوشه‌های HuggingFace)
- 🎨 **رابط کاربری وب حرفه‌ای**: داشبوردی زیبا با تم تاریک (Dark Mode) برای مدیریت مدل‌ها

- 📊 **مانیتورینگ لحظه‌ای**: نمایش مصرف CPU و RAM به‌صورت زنده
- 🎮 **مدیریت پروسه**: شروع و توقف آسان سرور با یک کلیک
- 📝 **نمایش لاگ**: مشاهده‌ی خروجی سرور برای عیب‌یابی
- 🔧 **قابل توسعه**: ساختار کد به‌گونه‌ای طراحی شده که افزودن پشتیبانی از فریم‌ورک‌های جدید به راحتی امکان‌پذیر است.
- 🌐 **دسترسی از راه دور**: امکان اتصال از دستگاه‌های دیگر در شبکه محلی

## 📂 آماده‌سازی مدل‌ها
پوشه‌ای به نام `models` در ریشه‌ی پروژه بسازید (اگر وجود ندارد). مدل‌های خود را به یکی از دو روش زیر در این پوشه قرار دهید:

| نوع مدل | روش قرار دادن در پوشه‌ی `models` | مثال |
| :--- | :--- | :--- |
| **GGUF** (فایل `.gguf`) | فایل `.gguf` را مستقیماً کپی کنید. | `models/llama-2-7b.Q4_K_M.gguf` |
| **Transformers** (پوشه‌ی HuggingFace) | پوشه‌ی حاوی `config.json` و فایل‌های وزن مدل را کپی کنید. | `models/gemma-2b/` (شامل config.json, pytorch_model.bin و ...) |

> **نکته:** می‌توانید مدل‌های GGUF را از سایت HuggingFace یا منابع معتبر دیگر دانلود کنید.

## 🔌 اتصال به مدل از طریق Base URL
بعد از استارت سرور، مدل از طریق آدرس `http://127.0.0.1:{port}/v1` در دسترس است. این سرور با OpenAI API کاملاً سازگار است، بنابراین می‌توانید از ابزارهای مختلف برای ارتباط با آن استفاده کنید.

### مثال با `curl` در ترمینال
```bash
curl http://127.0.0.1:8000/v1/completions \
  -H "Content-Type: application/json" \
  -d '{"prompt": "سلام، چطوری؟", "max_tokens": 50}'
```

### مثال با کتابخانه‌ی `requests` در پایتون
```python
import requests

response = requests.post(
    "http://127.0.0.1:8000/v1/completions",
    json={"prompt": "معنی زندگی چیست؟", "max_tokens": 100}
)

if response.status_code == 200:
    print(response.json()["choices"][0]["text"])
else:
    print("خطا:", response.text)
```

### اتصال از دستگاه‌های دیگر در شبکه
اگر می‌خواهید از دستگاه دیگری در شبکه به سرور متصل شوید:
1. در فایل `app.py` مطمئن شوید `host='0.0.0.0'` است.
2. آدرس IP دستگاه خود را پیدا کنید (در ویندوز با دستور `ipconfig` و در لینوکس با `ifconfig`).
3. از آدرس `http://{IP-ADDRESS}:8000/v1` استفاده کنید.

## 🛠️ عیب‌یابی خطاهای رایج

| خطا | علت | راه‌حل |
| :--- | :--- | :--- |
| `ConnectionRefusedError: [WinError 10061]` | سرور مدل روی پورت مشخص‌شده بالا نیامده است. | ۱. مطمئن شوید `llama-cpp-python[server]` به‌درستی نصب شده است.<br>۲. پورت را به عدد دیگری تغییر دهید (مثلاً `8001`).<br>۳. لاگ‌ها را بررسی کنید تا خطای دقیق را ببینید. |
| `ModuleNotFoundError: No module named 'llama_cpp'` | کتابخانه‌ی مورد نیاز نصب نشده است. | کتابخانه را مجدداً نصب کنید: `pip install llama-cpp-python[server] --force-reinstall` |
| `Address already in use` | پورت مورد نظر توسط برنامه‌ی دیگری اشغال شده است. | پورت را به عدد دیگری تغییر دهید یا برنامه‌ی اشغال‌کننده را ببندید. |
| `OutOfMemoryError` (برای مدل‌های Transformers) | رم سیستم برای بارگذاری مدل کافی نیست. | ۱. مقدار Context Length را کاهش دهید (مثلاً به 1024 یا 2048).<br>۲. از مدل کوچک‌تری استفاده کنید (مثلاً نسخه‌ی ۳ میلیارد پارامتری به جای ۷ میلیاردی). |
| **مدل در لیست نمایش داده نمی‌شود** | مدل در پوشه‌ی `models/` قرار ندارد یا فرمت آن پشتیبانی نمی‌شود. | مطمئن شوید فایل `.gguf` یا پوشه‌ی حاوی `config.json` در مسیر `models/` قرار دارد. |
| **لاگ‌ها خالی یا به‌روز نمی‌شوند** | فایل لاگ ایجاد نشده یا دسترسی به آن وجود ندارد. | پوشه‌ی `logs/` را در ریشه‌ی پروژه بسازید و مطمئن شوید برنامه دسترسی نوشتن روی آن را دارد. |
| **صفحه‌ی داشبورد باز نمی‌شود** | پورت ۵۰۰۰ اشغال است یا Flask اجرا نشده است. | پورت Flask را در `app.py` تغییر دهید یا پروسه‌ی قبلی را ببندید. |

## ⚙️ نکات پیشرفته برای کاربران حرفه‌ای

### تغییر تعداد نخ‌های پردازشی (Threads)
به‌صورت پیش‌فرض، برنامه از نصف هسته‌های منطقی CPU استفاده می‌کند. برای تغییر این مقدار، در فایل `app.py`، هنگام فراخوانی `start_server`، مقدار `n_threads` را به عدد دلخواه تغییر دهید.

### ذخیره‌سازی لاگ‌ها
همه‌ی خروجی‌های سرور در فایل `logs/server.log` ذخیره می‌شوند. می‌توانید این فایل را برای بررسی دقیق‌تر خطاها باز کنید.

### اتصال از راه دور (شبکه محلی)
اگر می‌خواهید از دستگاه دیگری در شبکه به سرور متصل شوید، در فایل `app.py` مطمئن شوید که `host='0.0.0.0'` است. سپس به جای `127.0.0.1` از آدرس IP دستگاه خود استفاده کنید.

### اضافه کردن پشتیبانی از فریم‌ورک جدید
برای افزودن پشتیبانی از فریم‌ورک‌های دیگر (مانند ExLlamaV2، MLC یا GPTQ-for-LLaMA)، کافی است متد `start_server` را در فایل `model_loader.py` گسترش دهید و یک شرط جدید برای نوع مدل مورد نظر اضافه کنید.

### تنظیمات پیش‌فرض مدل‌های Transformers
در صورت نیاز، می‌توانید پارامترهای `device_map` و `torch_dtype` را در بخش Transformers در `model_loader.py` تغییر دهید تا مدل روی GPU یا با دقت متفاوت بارگذاری شود.
